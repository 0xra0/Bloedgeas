# Changelog

## v1.0.0 — 2026-11-13

Initial GitHub release of the Bloedgeas custom steel sword snapshot, targeting The Witcher 3: Wild Hunt — Remastered 5.01c.

- Custom v6 sword/scabbard models, textures, inventory icon, and item description.
- Human-target bleed, combat regeneration, rune flares, life-drain beam, and killing-blow blood burst.
- Randomized custom hit/bleed audio and a low-health heartbeat/glow.
- Compatible Gear Level Scaling snapshot and the verified saved-item scaling correction.
- English and Ukrainian text, plus the installed snapshot's English fallback language files.
- Installation, usage, compatibility, troubleshooting, source-pipeline, and packaging documentation.
- A ready-to-install ZIP with internal file hashes and a separate archive SHA-256 checksum.

The retained in-game record confirms level 42 → 54 and base damage 369 → 465 for an existing sword copy. Regeneration is currently fixed at 0.4% maximum vitality per second while drawn in combat; the proposed stronger low-health curve is not implemented.
